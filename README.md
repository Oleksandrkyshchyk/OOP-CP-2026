# Carpooling.App

## Опис проєкту
**Carpooling.App** — це desktop-застосунок платформи для організації спільних поїздок, розроблений у межах курсового проєкту з дисципліни **«Об’єктно-орієнтоване програмування»**.

Програма реалізує базовий функціонал сервісу пошуку попутників: реєстрацію та авторизацію, пошук маршрутів, публікацію оголошень водіями, бронювання місць пасажирами, а також повне адміністрування та модерацію системи.

## Мета проєкту
Метою проєкту є розроблення програмного забезпечення для предметної області **організація спільних поїздок** з використанням об’єктно-орієнтованої парадигми, графічного інтерфейсу користувача та збереження даних між сеансами роботи програми.

## Основний функціонал
- пошук поїздок за містами відправлення, прибуття та датою;
- реєстрація та авторизація користувачів;
- розмежування прав доступу залежно від ролі;
- внесення даних про автомобіль в особистому кабінеті водія;
- створення та публікація нових поїздок водіями;
- бронювання місць пасажирами з автоматичним оновленням кількості вільних місць;
- перегляд та скасування власних поїздок або бронювань;
- перегляд повної статистики системи адміністратором;
- керування користувачами та модерація поїздок адміністратором;
- збереження та завантаження даних у форматі JSON.

## Ролі користувачів

### Гість
- переглядає доступні поїздки через пошук;
- переглядає загальну інформацію про маршрути;
- створює новий обліковий запис.

### Пасажир
- авторизується в системі;
- переглядає детальну інформацію про поїздку (дані автомобіля, контакти водія);
- бронює місце в активній поїздці;
- переглядає список бронювань та скасовує їх у разі потреби.

### Водій
- авторизується в системі;
- додає та оновлює інформацію про свій автомобіль;
- створює та публікує нові поїздки (за наявності автомобіля);
- переглядає список створених поїздок та скасовує їх.

### Адміністратор
- авторизується в системі;
- переглядає загальну статистику (кількість користувачів, активні поїздки, фінансовий оборот);
- переглядає список користувачів, змінює їхні дані та видаляє акаунти;
- скасовує або видаляє поїздки;
- здійснює ручне збереження та завантаження актуального стану бази даних.

## Основні вікна програми
У проєкті реалізовані такі вікна:
- **MainWindow** — головне вікно програми;
- **LoginWindow** — вікно авторизації користувачів;
- **RegistrationWindow** — вікно реєстрації нових акаунтів;
- **SearchResultsWindow** — вікно з результатами пошуку та фільтрації поїздок;
- **TripDetailsWindow** — вікно детальної інформації про обрану поїздку та бронювання;
- **ProfileWindow** — особистий кабінет користувача (водія або пасажира);
- **CreateTripWindow** — вікно створення та публікації нової поїздки;
- **AdminWindow** — панель адміністратора для модерації та перегляду статистики.

## Збереження даних
У програмі реалізовано збереження та завантаження даних у локальні файли:
- `users.json` — база даних користувачів із підтримкою поліморфної серіалізації;
- `trips.json` — база даних поїздок та вкладених бронювань.
